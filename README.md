# SMTP relay for Railway

Send email over SMTP from any Railway plan.

Railway blocks outbound SMTP (ports 25, 465, 587 and 2525) on the Free, Trial and Hobby plans, so apps that send through an SMTP server time out with `Connection timeout` or `Network is unreachable`. This relay runs next to your app in the same Railway project. Your app sends SMTP to it over Railway's private network, which isn't blocked, and the relay delivers each message over HTTPS with [Groundmail](https://groundmail.dev).

Nothing in your app changes except its SMTP settings. It works for anything that only speaks SMTP: Ghost, n8n, Django, Rails, Laravel, WordPress, Supabase Auth, Nodemailer, and so on.

```
your app ──SMTP (private network)──▶ smtp-relay ──HTTPS──▶ Groundmail ──▶ inbox
```

## Deploy

1. [Create a Groundmail account](https://app.groundmail.dev/signup) (free for 3,000 emails a month), verify your sending domain, and create an API key.
2. Deploy the template on Railway: [railway.com/deploy/groundmail-smtp-relay](https://railway.com/deploy/groundmail-smtp-relay). Paste your API key when it asks for `GROUNDMAIL_API_KEY`.
3. Point your app's SMTP settings at the relay (below).

## Your app's SMTP settings

| Setting | Value |
|---------|-------|
| Host | `${{smtp-relay.RAILWAY_PRIVATE_DOMAIN}}` (for example `smtp-relay.railway.internal`) |
| Port | `2525` |
| Encryption | None (traffic never leaves Railway's private network) |
| Username | `${{smtp-relay.SMTP_USERNAME}}` (default `groundmail`) |
| Password | `${{smtp-relay.SMTP_PASSWORD}}` |
| From address | An address on the domain you verified in Groundmail |

Use Railway's reference variables (`${{smtp-relay.…}}`) so the values stay in sync. If you renamed the relay service, use its name instead of `smtp-relay`.

### Examples

**Nodemailer**

```js
const transporter = nodemailer.createTransport({
  host: process.env.SMTP_HOST,
  port: 2525,
  secure: false,
  ignoreTLS: true,
  auth: { user: process.env.SMTP_USERNAME, pass: process.env.SMTP_PASSWORD },
})
```

**Django**

```python
EMAIL_HOST = os.environ["SMTP_HOST"]
EMAIL_PORT = 2525
EMAIL_HOST_USER = os.environ["SMTP_USERNAME"]
EMAIL_HOST_PASSWORD = os.environ["SMTP_PASSWORD"]
EMAIL_USE_TLS = False
```

**Ghost**

```
mail__transport=SMTP
mail__options__host=${{smtp-relay.RAILWAY_PRIVATE_DOMAIN}}
mail__options__port=2525
mail__options__secure=false
mail__options__auth__user=${{smtp-relay.SMTP_USERNAME}}
mail__options__auth__pass=${{smtp-relay.SMTP_PASSWORD}}
```

**n8n**

```
N8N_EMAIL_MODE=smtp
N8N_SMTP_HOST=${{smtp-relay.RAILWAY_PRIVATE_DOMAIN}}
N8N_SMTP_PORT=2525
N8N_SMTP_SSL=false
N8N_SMTP_USER=${{smtp-relay.SMTP_USERNAME}}
N8N_SMTP_PASS=${{smtp-relay.SMTP_PASSWORD}}
```

## Configuration

| Variable | Default | |
|----------|---------|---|
| `GROUNDMAIL_API_KEY` | (required) | Your Groundmail API key |
| `SMTP_PASSWORD` | generated by the template | Password your app logs in with. Leave empty to accept mail without a login (private network only) |
| `SMTP_USERNAME` | `groundmail` | Username your app logs in with |
| `SMTP_PORT` | `2525` | Port the relay listens on |
| `MAX_MESSAGE_BYTES` | `41943040` (40 MB) | Largest message accepted |

## What gets delivered

- To, Cc and Bcc follow the SMTP envelope, so Bcc works the way it does with any mail server.
- HTML and text parts, Reply-To, attachments and inline images are kept.
- Custom headers like `List-Unsubscribe` and `In-Reply-To` are passed through.
- `X-Groundmail-Tag: name=value` adds a tag you can filter by in the dashboard, and `X-Groundmail-Idempotency-Key` stops duplicate sends.

If Groundmail rejects a message (for example, the From domain isn't verified), your app gets a `550` with the reason. Temporary problems return `451`, so your app's mail library retries.

Every message shows up in your [Groundmail dashboard](https://app.groundmail.dev/emails) with its delivery status.

## Don't need SMTP?

If you control the code, send with the [Groundmail API or SDKs](https://docs.groundmail.dev) directly. HTTPS works on every Railway plan and you skip the relay.

## Run locally

```bash
npm install
GROUNDMAIL_API_KEY=gm_... SMTP_PASSWORD=dev npm start
npm test
```
